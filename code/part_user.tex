\chapter{User Options} \label{chap:user-options}

After logging in, you will be directed to the \textsl{Home} page, which displays a welcome message along with several navigation options, and provides quick access to the main platform features.

\vspace{0.5cm}

\insertFigure[0.5]{toolbar-researcher}{Navigation links for a generic user.}

\begin{itemize}
	\item \textbf{Home}: redirects to the main page (see \docref{Chapter}{chap:user-homepage}).
	\item \textbf{Info}: access to platform information (see \docref{Chapter}{chap:user-platform-info}).
	\item \textbf{Science}: access to science information (see \docref{Chapter}{chap:user-science}).
	\item \textbf{Log out}: option to manually log out of the platform (see \docref{Chapter}{chap:user-logout}).
\end{itemize}
