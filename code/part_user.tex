\chapter{Accessing the Platform} \label{chap:user-access}

To start using \app, open your preferred web browser and navigate to the project URL, \prjUrl. It is recommended to use modern browsers such as \textsl{Chrome}, \textsl{Firefox}, or \textsl{Edge} for optimal compatibility with all platform features. Once the page loads, you will reach the welcome page. 

\vspace{0.5cm}

\insertFigure[0.8]{welcome}{Dwarfs4MOSAIC welcome page.}

Click the \texttt{LOGIN} option at the top-right corner of the page to access the login form and enter your assigned username and password in the corresponding fields. 

\insertFigure[0.40]{login}{Login form.}

If you forget your password or experience login issues, please contact \textsl{\prjContact} at \prjGuaix to request a new password.

\chapter{Navigating the Home Page} \label{chap:user-homepage}

The \textsl{Home} page shows a table with the targets you have permission to view.

%, depending on your user rol: \textsl{Core Team} members have full access to all entries, while \textsl{Collaborators} can only view the targets and blocks assigned to their group, with any restricted or denied blocks and associated data files remaining hidden.

\insertFigure{homepage}{Home page.}

Each target is displayed with several fields that provide key information at a glance:

\begin{description}
	\item[Image:] target's associated image, if available.
	\item[Name:] unique identifier of the target.
	\item[Type:] category of the astronomical object.
	\item[Right Ascension:] celestial coordinate along the equatorial plane [hh:mm:ss].
	\item[Declination:] celestial coordinate perpendicular to the equatorial plane [dd:mm:ss].
	\item[Apparent Magnitude:] brightness of the target as observed from Earth.
	\item[Redshift (z):] measured redshift of the object.
	\item[Angular Size:] apparent size of the target in the sky.
	\item[Visibility Semester:] semester when the target is visible.
	\item[Observing Run:] name of the observing run(s) the target belongs to.
	\item[Instrument:] instrument used to acquire data for the target.
	\item[Data Files:] list of associated files available for download (see \docref{Chapter}{chap:user-download-files}).
	\item[Comments:] additional information.
\end{description}

\chapter{Downloading Files} \label{chap:user-download-files} 
   	
On the \textsl{Home} page, locate the target of interest. In the \texttt{Data Files} column, you will see the available files along with the download icon {\scriptsize \grayblue{\faDownload{}}}. Clicking this icon opens the file download view.

\insertFigure[0.6]{download}{File download view.}

This view displays a table containing all the files associated with the selected target and their respective sizes. You can select one, multiple, or all files at once. If only a single file is selected, it will be downloaded directly. If multiple files are selected, a \textsl{.zip} archive containing all selected files is generated. The download process is handled directly by your web browser.

\chapter{Logging Out} \label{chap:user-logout}

To securely exit the platform, click the \texttt{LOG OUT} option located at the top-right corner of the page. This will end your session and return you to the welcome page. Your session will also automatically expire after 15 minutes of inactivity, requiring you to log in again. This helps protect your account on shared computers.

\warning Always log out when you finish using the system, especially on shared or public computers, to protect your account and data.
